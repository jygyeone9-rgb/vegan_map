- 일호빵 플래인 바게트는 플레인 바게뜨에 대응했다. 올리브치즈 바타르는 치즈 원료(유제품/식물성)가 불명확해 기존 분류와의 불일치 가능성을 설명하고 재확인을 요청했다. 기존 자료 분류는 검증 완료를 의미하지 않는다.
- 슬로우브레드 오고는 통밀 시골빵 9,000원과 통밀 100% 10,000원을 구분했다. 원자료의 크랜베리 시골빵과 현재 크랜베리 통밀빵은 동일성이 불확실해 가격을 채우지 않았다.
- 베러초이스는 공식몰 1개 가격이며 배송비·옵션금·현장 가격과 구분한다.

## 사진과 검증

사진 사용 허락은 확보하지 않았다. 재사용 동의가 없는 사진을 전재하거나 다운로드하지 않고, 정확한 메뉴 사진이 게재된 상품·메뉴 페이지로 연결한다. 사진을 특정하지 못한 항목에는 링크나 빈 이미지 칸을 만들지 않는다. 채육식당은 브랜드 공통 메뉴 사진 페이지로 연결하며 지점별 구성 차이를 표기한다.

가격·설명 보강은 기존 verification, dietTypes, crossContact, available, photoConsent를 변경하지 않는다. 콩고기 정식은 계란후라이 제외와 반찬·육수 확인을 설명에 명시했다. 비건 대체육이라는 표기가 전체 정식의 비건 여부를 증명하지 않는다.

## 다음 갱신 방법

가격 변경은 menu-enrichments.json에서 해당 메뉴만 갱신하고 출처·조회일·지점·원문 메뉴명을 함께 기록한다. npm test와 npm run build로 데이터·가격 검색을 검증한다. 가격 자료가 있는 메뉴만 필터로 현재 64곳을 찾아볼 수 있다.
