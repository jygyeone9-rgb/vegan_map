# 핸드북 반영 내역

원자료는 사용자가 제공한 **서울시 채식음식점 지도**입니다. 발행처는 서울시 시민건강국 식품정책과, 편집처는 한국비건진흥원이며, 발행은 2025년 11월, 조사 기준은 2025년 10월입니다. PDF 파일 61페이지는 인쇄본 118쪽까지의 펼침면을 포함합니다. 문서 안의 안내는 데이터로만 다루었습니다.

## 추출·대조
식당 번호 1–300을 모두 반영했습니다. 식당은 300곳(채식 전문 119, 가능 181), 메뉴는 841개(V 788, L 42, O 2, LO 9)입니다. 페스코 표기는 원자료에 없습니다. PDF 메뉴 이름과 분류를 유지했고, 메뉴명으로 재료나 비건 여부를 추론하지 않았습니다. 가격·전체 재료·현재 판매 여부·교차접촉·영업시간은 별도 미확인으로 남겼습니다.

PDF를 반으로 나눠 각 식당 카드를 추출하고, 서울시 스마트서울맵의 공개 채식음식점 테마(`1734937216464`)와 상호·주소·전화번호를 대조했습니다. 유형 표기는 모든 메뉴에 원본 페이지와 연결했습니다. 공식 지도와 메뉴 수나 텍스트가 다른 항목(38·64·76·124·167·191·293·298번 등)은 해당 원본 페이지를 렌더링해 확인했습니다. 서로 다른 자료의 메뉴를 합치거나 PDF에 없는 메뉴를 추가하지 않았습니다.

127번은 중복 텍스트 레이어를 정리했고, 197번 칙피스 신사점은 겹쳐 추출되는 가능/전문 텍스트를 인쇄본 79쪽의 보이는 **전문** 표기와 대조했습니다. PDF의 줄임·표기 차이(예: 38번 ‘모닝 치아바’, 293번 ‘피타 볼+셀프’)는 임의로 다른 자료의 메뉴명으로 교체하지 않았습니다. 298번 첫 메뉴는 PDF와 서울시 지도에 차이가 있어 PDF 표기를 유지했습니다.

## 위치 보완
297곳은 상호·주소(필요 시 전화번호)를 대조한 스마트서울맵 좌표를 사용합니다. 중복 이름인 슬금슬금은 전화번호와 메뉴가 맞는 콘텐츠 `v_0063`을 선택했습니다. 175번의 PDF ‘리브팜’과 지도 ‘리프팜’ 표기 차이는 같은 주소와 메뉴를 대조했습니다.

공식 지도에서 대응 항목을 찾지 못한 3곳은 PDF의 식당명과 주소를 기준으로 아래 위치 자료를 대조했습니다.
- 128 아날로그가든: [OpenStreetMap 장소](https://www.openstreetmap.org/node/5253331921), 서교동 동교로 145.
- 129 어라운드그린: [Placeview의 네이버 지도 위치](https://placeview.co.kr/id/MTEzMjYwNjY4NyAg), 합정동 동교로 44-1.
- 149 황금룡: [뽈레의 네이버 지도 위치](https://polle.com/place/4xnTZO/황금룡), 망원동 포은로 90.

167 듀공 역삼점은 PDF가 **언주로71길 5-4**, 서울시 지도가 **강남대로 328**로 서로 다릅니다. PDF 주소를 보존하고, 지도에는 서울시 좌표를 사용하며 주소 재확인용 표식과 두 주소를 상세 화면에 표시합니다. 어느 주소가 최신인지 단정하지 않습니다.

좌표는 장소 탐색용 출처 보완이며, 전체 식당의 최신 영업 상태를 확인했다는 뜻이 아닙니다. 각 좌표의 출처·원래 주소·콘텐츠 ID는 `scripts/handbook-locations.json`과 식당 JSON에 보존합니다.

## 사진과 외부 링크
네이버·Google 지도의 검색 가능한 사진에서 정확한 메뉴·지점과 사용 가능한 이미지 주소를 확보하지 못했습니다. 현재 메뉴 이미지는 모두 비워두었으며 UI에는 설명만 표시합니다. 원본 PDF의 사진도 메뉴별로 임의 복제하지 않았습니다.

공식 SNS는 대조한 서울시 지도 자료에 연결된 링크를 기록했습니다. 네이버·Google의 검색 링크는 정확한 지점 리뷰 링크와 별도로, 검색임을 표시해 제공합니다. 새로운 가격·영업시간·메뉴 정보는 이번 반영에서 외부 리뷰로 대체하지 않았습니다.

## 검증과 재현
`import-handbook.py`는 식당 번호 누락/중복과 메뉴 수 변화를 검사하고 원본 파일 SHA-256을 기록합니다. 앱 데이터 검증은 ID 참조, 25개 자치구, 좌표·출처, 원문 태그와 유형 일치, 사진 근거, 자료 상태와 개별 재확인 상태를 검사합니다. 자동 테스트에는 전체 가져오기 건수·유형 분포, 5가지 필터, 전문점의 유제품 메뉴, 주소 불일치와 사진 없음 처리가 포함됩니다.

원자료 배포처: [서울시](https://fsi.seoul.go.kr/front/M0000070/board/view.do?atcSn=2283), [한국비건진흥원](https://k-vegan.org/?page_id=4337&uid=644&mod=document&pageid=1).

## 실행 확인
로컬 데이터 검증과 자동 테스트 12개, Vite 프로덕션 빌드가 통과했습니다. 브라우저에서 지도 마커 300개와 결과 수 300곳·841개 메뉴, 성동구+오보 검색, 전문점+락토 검색, 페스코 빈 결과, 메뉴 더 보기(24→48), 즐겨찾기 저장 후 새로고침 유지, Escape로 닫기, 사진 영역 없음이 동작했습니다. 390px 모바일과 1440px 데스크톱에서 가로 넘침이 없었고 확인 중 브라우저 콘솔 오류는 없었습니다.
